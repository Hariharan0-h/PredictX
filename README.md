# PredictX — Smart Failure Prediction Engine for Industrial Systems

Contextual predictive maintenance system combining IoT sensor data (AI4I 2020) with simulated external context to forecast machine failures using LightGBM + SMOTE. Built for the Infotact DS/ML Internship (Project 1).

**Primary KPI:** Macro F1 ≥ 0.85 under synthetic sensor noise.

---

## Setup

```bash
git clone <repo-url>
cd PredictX-Smart-Failure-Prediction-Engine-for-Industrial-Systems

python -m venv venv

pip install -r requirements.txt

# Install nbstripout pre-commit hook (strips notebook outputs before commit)

```

## Pipeline

Run steps in order:

```bash
python src/ingest.py      # Download AI4I dataset → data/raw.parquet
python src/features.py    # Rolling window features → data/features_internal.parquet
python src/context.py     # Simulate external context + ablation → data/features_fused.parquet
python src/train.py       # SMOTE-inside-CV LightGBM → models/pipeline.pkl
python src/evaluate.py    # Noise injection + PR curve → outputs/pr_curve_noisy.png
python src/explain.py     # SHAP values → outputs/shap_*.png
```

**Optional — hyperparameter tuning (run before train.py):**

```bash
python src/tune.py              # 50 trials (default)
python src/tune.py --trials 100 # more thorough sweep
# saves results/best_params.json → auto-loaded by train.py
```

## Architecture

```
src/
  ingest.py    → Downloads AI4I 2020 (UCI id=601), validates failure rate < 5%
  features.py  → Rolling mean / std / var (window=10) on 5 sensor columns
  context.py   → Simulates ambient_temp_ext + factory_load; runs ablation study
  train.py     → imblearn Pipeline: StandardScaler → SMOTE → LGBMClassifier
  evaluate.py  → Gaussian noise injection (σ=0.1×std), PR curve, threshold sweep
  explain.py   → SHAP TreeExplainer: summary bar + beeswarm plots
  tune.py      → Optuna TPE sweep over LightGBM params (optional, improves train.py)

data/           gitignored — re-generated by pipeline
models/         gitignored — re-generated by train.py
outputs/        generated plots (pr_curve_noisy.png, shap_*.png)
results/        JSON metric logs (cv_scores.json, ablation.json, eval_metrics.json)
notebooks/      EDA only — outputs stripped on commit
tests/          pytest suite (12 tests covering features, SMOTE leakage, context)
```

## Critical Implementation Notes

- **SMOTE leakage:** SMOTE lives inside `imblearn.Pipeline` and only fits on training folds — never on the full dataset before CV splitting.
- **Decision threshold:** tuned on the validation PR curve, not the default 0.5.
- **Ablation:** `context.py` trains internal-only vs. fused features and logs the Macro F1 delta to `results/ablation.json`.
- **Noise robustness:** `evaluate.py` injects Gaussian noise (σ = 0.1 × per-feature std) to test set sensor columns only.
